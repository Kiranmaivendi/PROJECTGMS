# PROJECTGMS

PROJECTGMS is a Unity project with scenes for `SampleScene` and `ZombieRunnerFactory`. It also includes a `GemSpin` component for rotating scene objects.

## Requirements

- Unity **6000.5.8f1**

## Open the project

1. In Unity Hub, choose **Add** and select this repository folder.
2. Open the project with Unity 6000.5.8f1 and allow Unity Package Manager to resolve the packages listed in `Packages/manifest.json`.
3. Open either `Assets/Scenes/SampleScene.unity` or `Assets/ZombieRunnerFactory.unity`.

Both scenes are listed in the project's build settings. To create a build, choose **File > Build Profiles** in the Unity Editor and select your target platform.

## Project structure

- `Assets/` — scenes, scripts, prefabs, materials, and other game assets
- `Packages/` — Unity package manifest and lock file
- `ProjectSettings/` — Unity editor and player settings
